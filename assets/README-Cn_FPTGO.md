# Original fox artwork example

This skin supplies a silver-grey alternative to the default fox illustration using a transparent, non-square PNG. Append `?skins=skins/default,examples/fox-art` to the playtest URL. All ecological rules and state hashes stay the same.

The default and alternative images are original path-based Canvas drawings generated by `web/scripts/make-sprite-example.mjs`. No external images or fonts were used. The generation source is included so the provenance is reviewable. This is original project content; the example grants no new redistribution license. It demonstrates the artwork pipeline, not a new species or a simulation change.
